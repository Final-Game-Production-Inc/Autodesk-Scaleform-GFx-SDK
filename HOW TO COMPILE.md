Let Me Teach You How To Compile Scaleform GFx SDK.

Before Compile, You Need
1. Microsoft DirectX SDK (June 2010)
2. Vulkan SDK
3. 3rdParty.7z, Download in [Here](https://github.com/Final-Game-Production-Inc/Autodesk-Scaleform-GFx-SDK/releases/tag/v4.5.32-November-Rain-Update)
4. Data Folder, Is Included In BinUtils.zip, Download in [Here](https://github.com/Final-Game-Production-Inc/Autodesk-Scaleform-GFx-SDK/releases/tag/v4.5.32-November-Rain-Update)
And Extract In Bin Folder.

Viedo Default Is Sofdec2, If You Want To Build FFMpeg Video, Download In [Release](https://github.com/Final-Game-Production-Inc/Autodesk-Scaleform-GFx-SDK/releases/tag/v4.5.32-November-Rain-Update)
<p>
FFMpeg.7z.001<br>
FFMpeg.7z.002<br>
FFMpeg.7z.003
</p>

Or Download In [Here](https://drive.google.com/file/d/1FF0WjH0TK6Z0KfTwBefRSZAeeY6TGYkQ/view?usp=drive_link)

Then Extract In 3rdparty.

Next, Go Projects/Win32/Msvc18/SDK, You Can See
1. GFx 4.5.32 Leslie 3rd Party.slnx
2. GFx 4.5.32 Leslie SDK And Demo.slnx
3. GFx 4.5.32 Leslie SDK.slnx
4. GFx 4.5.32 Leslie Tools.slnx

<p>
If You Want To Rebuild 3rdparty, Choice 1.<br>
If You Want To Build SDK Or SDK And Demo, Choice 2 or 3.<br>
Build Tools, Choice 4. (GFxShaderMaker Should Be Set In Bin/Tools/GFxShaderMaker, Can Using Command Easily, For More Information, See ReadMe.txt For GFxShaderMaker)
</p>

If You Wanna Start Quickly, You Can Download [Lib.7z](https://github.com/Final-Game-Production-Inc/Autodesk-Scaleform-GFx-SDK/releases/download/v4.5.32-November-Rain-Update/Lib.7z)
And Extract In Lib Folder.

Scaleform Docs 4.1-4.4.zip Can Help You How To Start For Scaleform SDK Development.<br>
And Release Has "Video.FFMpeg.Reference.Manual.md" Or "Video.FFMpeg.Reference.Manual.EN.md"<br>
Can Help You How To Use Scaleform FFMpeg Video.
